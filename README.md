# ⚖️ ערעור בקליק

אתר שעוזר לבטל דוחות. מצלמים את הדוח, עונים על כמה שאלות, ומקבלים:

- את **המסלול** (פלילי או מנהלי) ואת **התאריכים המדויקים** להגשה
- **ציון לכל טענה**: חזקה, בינונית, או כזו שעדיף לוותר עליה
- **כרטיס פעולה**: מה מגישים, לאן, עד מתי ומה מצרפים
- **מכתב מוכן** (בקשה לביטול, השגה, או הסבה לנהג אחר) עם כפתור **שליחה**

סוגי דוחות: חניה עירונית, דוח משטרה (שוטר), דוח מצלמה ונת"צ.

## איך זה עובד: "מוח" משלנו, בלי AI

כל ההחלטות נעשות בקוד שלנו, לפי החוק. אין שום שירות AI חיצוני, ואין תשלום לפי שימוש.

| חלק | קובץ | מה הוא עושה |
|---|---|---|
| קריאת התמונה | `js/ocr.js`, `js/engine/ocr-parse.js` | מזהה את הטקסט בתמונה (Tesseract, רץ בדפדפן) ומוציא ממנו מספר דוח, תאריכים, סכום, לוחית ועירייה. המשתמש מאשר ומתקן. |
| מסלול ומועדים | `js/engine/deadlines.js` | מחשב פלילי או מנהלי לפי תאריך העבירה והסכום, ואת כל התאריכים האחרונים, כולל דחייה משבת. |
| עילות הערעור | `js/engine/grounds.js` | טבלת הטענות לכל סוג דוח, עם ציון, הסבר והראיה שצריך להשיג. |
| המוח | `js/engine/analyze.js` | מחבר הכול: בודק איחור במשלוח, מדרג טענות, בוחר עד 3 חזקות למכתב, מסנן טענות שמפסידות תמיד. |
| המכתבים | `js/engine/letters.js` | בונה את המכתב לפי התבניות. |
| לאן שולחים | `js/engine/send.js` | רק קישורים רשמיים מאומתים (gov.il, עיריית תל אביב), או מייל לכתובת שעל הדוח. |
| הממשק | `index.html`, `js/app.js`, `css/style.css` | האשף בשלבים. |

**מקור הידע המשפטי:** הסקיל `jewish-legal-assistant` (רישיון MIT) שנמצא ב-`.claude/skills/`. כל סעיף ומספר מגובה שם ב-`evidence.json`, נכון ל-30.10.2026.

**פרטיות:** התמונה והפרטים לא יוצאים מהמכשיר של המשתמש. אין שרת, ואין מסד נתונים.

## להריץ במחשב

```bash
python3 -m http.server 8000
```

ואז לפתוח בדפדפן: http://localhost:8000

(צריך שרת קטן כזה, כי פתיחה ישירה של `index.html` מהקובץ לא תעבוד עם קריאת התמונה.)

## בדיקות

```bash
npm test
```

הבדיקות כוללות את תרחישי הבדיקה של הסקיל: סימון דהוי בתל אביב, מצלמה שהגיעה אחרי 5 חודשים, נהג אחר, נת"צ למונית, ודוח שהמועד הראשון שלו עבר.

## להעלות לאינטרנט

האתר הוא קבצים סטטיים בלבד, ולכן אפשר להעלות אותו בחינם:

- **Netlify** (הכי פשוט): נכנסים ל-https://app.netlify.com/drop וגוררים את תיקיית הפרויקט.
- **Vercel** או **Cloudflare Pages**: מחברים את הריפו בגיטהאב, בלי הגדרות בנייה.
- **GitHub Pages**: עובד בחינם רק לריפו ציבורי (או בחשבון בתשלום).

## תשלום לכל דוח

בקובץ `js/config.js`:

```js
payment: { enabled: true, priceILS: 29, paymentUrl: 'https://...' }
```

יוצרים "קישור תשלום" בחברת סליקה (Cardcom, PayPlus, Tranzila, Grow, Stripe) ומדביקים אותו. **מגבלה:** באתר סטטי אין אימות שהתשלום באמת בוצע (המשתמש לוחץ "שילמתי"). לאימות אמיתי צריך שרת קטן שמקבל אישור מחברת הסליקה (webhook) ורק אז משחרר את התוצאות. זה השלב הבא אם רוצים לגבות ברצינות.

⚠️ **לפני שגובים כסף:** בישראל ייעוץ משפטי בתשלום שמור בחוק לעורכי דין (חוק לשכת עורכי הדין). כדאי לבדוק עם עורך דין איך להציג ולבנות את השירות.

## לעדכן כשהחוק משתנה

- תאריכי השלבים והסכומים: בראש `js/engine/deadlines.js`
- טענות וציונים: `js/engine/grounds.js`
- קישורים להגשה: `js/engine/send.js`
- נוסח המכתבים: `js/engine/letters.js`

אחרי כל שינוי: `npm test`.

## מגבלות ידועות

- חגים לא נבדקים בחישוב המועדים (רק שבת). האתר אומר למשתמש להגיש כמה ימים לפני.
- קריאת התמונה עובדת טוב על צילום ישר וברור. בצילום מטושטש המשתמש משלים ידנית.
- לרוב העיריות אין טופס מקוון אחיד, ולכן "שליחה" היא: מייל לכתובת שעל הדוח, או העתקת המכתב ופתיחת הטופס הרשמי.
